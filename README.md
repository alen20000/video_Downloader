

# 🌐 85po Video Downloader
---
一個專為 85po 平台打造的圖形化（GUI）影片批次下載工具。
---

## ✨ 核心功能
- **🚀 智能批次下載**：支援同時輸入並批量下載最多 10 組目標網址。
- **📝 自動提取命名**：下載時自動解析並擷取影片名稱，完成自動命名。
- **📺 最高畫質保證**：後台自動爬取並解析，預設下載最高畫質影片。

---

## 📦 使用方法

1. **啟動程式**：於專案根目錄下執行 `main.py` 開啟圖形化視窗。
2. **貼上網址**：將要下載的 85po 影片網址，直接複製並貼入視窗中的網址輸入框內（預設提供 10 個欄位）。

<img src="assets/demo.png" width="220" alt="工具畫面示範">

3. **開始下載**：確認網址填寫無誤後，點擊 **「開始下載」** 按鈕，程式即會啟動自動化爬取與下載流程。
